Problem
Retail investors face high friction while accessing regulated financial instruments due to repeated identity verification, complex onboarding, and lack of reusable credentials.

Solution
MetaVault provides a portable investor verification system where identity checks are completed once and can be reused across platforms without re-submitting documents, reducing onboarding time and cost.

System Flow
1. User completes identity verification once
2. Verification proof is generated and stored securely
3. Platforms verify the proof instead of repeating KYC
4. User gains faster access to investment platforms

Tech Stack
- Frontend: Web-based UI
- Backend: Node.js
- Smart Contracts: Solidity
- Storage: IPFS
- Authentication: Magic Link
- Blockchain Network: Testnet
